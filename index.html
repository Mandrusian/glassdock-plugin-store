GET STARTED

Pick a plugin. Make it yours.

GlassDock's store reads this site's index.json. Individual .py files are verified by SHA-256 before installation.

01

Open GlassDock

Go to Settings → Extensions → Manage plugins….

02

Browse the store

Select Browse plugin store… and use the store address below.

03

Review & enable

Inspect the source and approve only the widgets you trust. Plugins run as your user, not in a sandbox.
